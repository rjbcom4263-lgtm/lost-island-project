# 살아 있는 세계지도

Cloudflare Pages에서 `/explore/`로 제공하는 2D 탐험 미리보기입니다. Unity 설치나 데이터베이스 없이 브라우저에서 실행합니다.

- 14개 권역 검색, 탐험 단계 필터, 권역 설명
- 지도 드래그, 확대·축소, 전체 보기, 패널 접기
- 공룡 2종·익룡 1종·해양 파충류 1종, 총 10개체의 왕복 이동과 신체 애니메이션
- 생물 관찰창, 지도에서 개체 찾기, 생물·탐사 항로 숨기기
- 일시정지, 키보드 탐색, 작은 화면 배치, 움직임 줄이기 설정 지원

지도와 생물 배치, 항로는 **Draft**입니다. 실제 생물 AI, 충돌·전투·채집·저장 기능은 포함하지 않습니다. 화면의 2D 스케치를 실제 게임용 3D 모델로 사용할 수는 없습니다.

## 수정할 파일

- `regions.json`: 권역 이름, 설명, 단계, 자원과 지도 좌표
- `app.js`: 개체 경로와 화면 조작
- `creatures.js`: 직접 작성한 SVG 생물과 애니메이션
- `style.css`: 화면 디자인과 반응형 배치

좌표는 원본 지도 이미지의 왼쪽 위가 `(0, 0)`인 픽셀 단위입니다. Leaflet 화면에 표시할 때 Y축을 뒤집으며, 실제 게임 월드 좌표와는 별개입니다.

원본 지도는 `docs/01-worldbuilding/assets/world-map-concept-v1.png`를 공유합니다. 웹 지도 엔진은 Leaflet 1.9.4이며 배포 파일과 BSD 라이선스는 `vendor/`에 포함했습니다.

## 로컬 확인

저장소 루트에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/explore/`를 엽니다. ES 모듈과 JSON을 불러오기 위해 `file://` 대신 HTTP로 열어야 합니다.
