# 저장 / 영속성

## 저장해야 하는 상태

### Player
- 식별자
- 위치
- 체력 / 스태미나
- 인벤토리
- 장비
- 스킬 / 숙련도

### World
- 현재 시간
- 자원 고갈 / 재생성 상태
- 날씨 및 지역 상태

### Building
- 고유 ID
- 타입
- 위치 / 회전
- 소유자
- 내구도
- 내부 저장소 참조

### Animal
MVP에서는 모든 야생동물을 영구 저장하지 않아도 된다. 길들인 동물 또는 특별 개체부터 영속화한다.

## 원칙

- 플레이어마다 별도 저장 ID 사용
- 월드 엔티티는 서버가 고유 ID 발급
- 클라이언트가 보낸 결과를 그대로 믿지 않음
- 자동 저장 + 정상 종료 저장 + 주기적 백업
