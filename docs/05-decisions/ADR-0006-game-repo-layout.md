# ADR-0006: 게임 프로젝트는 이 공개 저장소의 game/에 둔다

- 상태: 승인
- 날짜: 2026-11-10

## 결정

- Unity 게임 프로젝트를 이 저장소(공개)의 `game/` 폴더에 둔다. 문서와 게임 코드를 한곳에서 관리한다.
- 대용량 파일(모델, 텍스처, 오디오, 하이트맵, `.blend`)은 **Git LFS**로 관리한다.
- 협업 규칙
  - 닻섬을 **역할별 씬**으로 나눠 동시에 불러온다(예: `Terrain`, `Vegetation`, `Systems`, 쇼케이스 장소별 씬). 씬마다 담당자는 한 명이다.
  - 각자 브랜치에서 작업하고, 기능 단위 Pull Request로 `main`에 합친다.
- 라이선스는 아직 정하지 않는다.

## 이유

- 2인 팀이 문서와 코드를 한곳에서 보는 편이 단순하다.
- 씬과 프리팹은 동시에 고치면 병합이 거의 불가능하다. 역할(프로그래밍 / 기획·아트)이 나뉘어 있어서 역할별 씬 분리로 충돌을 피할 수 있고, 청크 스트리밍을 위한 씬 분할과도 구조가 같다.

## 결과

- 게임 코드와 실사 에셋이 모두 공개된다. 누구나 받아서 빌드할 수 있다.
- 라이선스 파일이 없는 동안은 법적으로 "모든 권리 보유" 상태다. 외부 공개 빌드나 후원을 시작하기 전에 라이선스를 다시 검토한다.
- 재배포가 허용되지 않는 에셋(일부 Unity Asset Store 에셋, 유료 텍스처 등)은 이 저장소에 올릴 수 없다. 그런 에셋이 필요해지면 이 결정을 다시 검토한다.
- GitHub LFS에는 무료 용량 제한이 있어서, 에셋이 늘면 유료 데이터 팩이 필요할 수 있다.

## 검토한 대안

- **새 비공개 저장소에 게임을 둠**: 후원 모델과 에셋 라이선스 면에서 안전하지만, 한곳에서 관리하는 편의를 우선했다.
- **이 저장소를 비공개로 전환**: 공개 위키와 탐험 지도를 따로 배포해야 해서 채택하지 않았다.
