# ADR-0001: 프로젝트 이름과 독립 IP 원칙

- 상태: 승인
- 날짜: 2026-09-12

## 결정

내부 프로젝트명은 **사라진섬 프로젝트 (Project Lost Island)** 로 한다.

특정 기존 게임의 명칭을 프로젝트 브랜드로 사용하지 않고 독립적인 세계관, 이름, UI, 아트, 데이터, 코드를 구축한다.

## 이유

- 독립적인 장기 프로젝트로 발전시키기 위해서
- 상표/저작권 등 불필요한 IP 리스크를 줄이기 위해서
- 기존 작품의 복원이 아니라 핵심 재미를 재해석한 신작으로 방향을 명확히 하기 위해서
