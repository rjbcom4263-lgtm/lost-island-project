# MVP 0.1 — First Camp

## 성공 조건

새 게임을 시작한 플레이어가 10~20분 안에 아래 루프를 끝낼 수 있다.

```text
채집 → 도구 제작 → 음식/전투 → 모닥불 → 상자/벽 → 저장 → 재접속
```

## 기능 범위

### 플레이어
- [ ] 이동
- [ ] 체력
- [ ] 스태미나
- [ ] 기본 상호작용

### 자원
- [ ] 나무
- [ ] 돌
- [ ] 풀
- [ ] 채집 횟수 / 고갈 상태

### 제작
- [ ] 돌도끼
- [ ] 칼
- [ ] 창
- [ ] 모닥불
- [ ] 상자

### 건축
- [ ] 바닥
- [ ] 벽
- [ ] 모닥불
- [ ] 상자

### 생물
- [ ] 초식 2종
- [ ] 포식자 1종
- [ ] 배회
- [ ] 플레이어 인식
- [ ] 공격 / 도주 최소 AI

### 전투
- [ ] 기본 공격

- [ ] 사망

### 저장
- [ ] 플레이어 위치
