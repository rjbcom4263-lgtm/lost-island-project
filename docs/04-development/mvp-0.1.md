# MVP 0.1 — First Camp (1차 데모)

## 목적

1. **루프 검증**: 새 게임을 시작한 플레이어가 10~20분 안에 아래 루프를 끝낼 수 있다.
2. **후원 유도**: 1차 데모는 후원을 끌어내기 위한 첫 공개 빌드다. 영상과 스크린샷에 보이는 장면의 완성도가 기능만큼 중요하다.

```text
채집 → 도구 제작 → 음식/전투 → 모닥불 → 상자/벽 → 저장 → 재접속
```

## 일정

- 목표: 약 3개월 (2027년 2월 초). **고정된 마감은 아니다.** 펀딩 시점도 정해져 있지 않다.

## 무대: 닻섬 전체

- 해안·숲·고지대·정착지 4개 지역
- 크기: 끝에서 끝까지 **2km 이상** (걸어서 20분 이상)
- 청크 스트리밍으로 가까운 구역만 불러온다
- 지형: 하이트맵 생성 도구 → Unity Terrain으로 가져와 손으로 다듬기
- 식생과 자원 노드: 규칙 기반 자동 배치 (예: 개울 근처엔 고사리, 고지대엔 바위)
- 쇼케이스 장소(해안이 보이는 숲속 거점, 폭포 등)는 손으로 배치

## 비주얼

- Unity 6 LTS + HDRP ([ADR-0003](../05-decisions/ADR-0003-engine-unity-hdrp.md))
- **실사 수준**을 목표로 한다
- 3D 모델은 Blender를 MCP로 연결해 직접 제작한다. 막히면 CC0 에셋으로 대체할 수 있다
- 타사 게임 에셋은 사용하지 않는다 ([연구 자료 운영 원칙](../03-research/research-policy.md))

## 카메라와 조작

- **고정 쿼터뷰 + 줌** (회전 없음)
- 캐릭터를 가리는 나무와 바위는 자동으로 반투명 처리한다
- **WASD 이동 + 마우스 조준**과 **클릭 이동**을 함께 지원한다
  - WASD를 누르면 클릭 이동은 취소된다
  - 두 방식 모두 같은 요청(`GatherRequest`, `AttackRequest` 등)으로 Simulation에 전달된다

## 생물 추가 방식

기본 3종(초식 2, 포식 1)으로 시스템 뼈대를 먼저 완성한다. 이후 생물은 Blender 모델 + 규칙 데이터(JSON) + 시각 데이터(ScriptableObject)만 추가해서 하나씩 늘린다.
