# 생태계 설계 v0.1

## 목표

생물은 단순 몬스터 목록이 아니라 **탐험·채집·전투·운송·제작을 연결하는 시스템**이어야 한다.

## 생물 역할 태그

각 생물은 최소 2개 이상의 역할을 가진다.

- Predator — 포식자
- Grazer — 초식/방목
- Scavenger — 청소동물
- Territorial — 영역 방어
- Pack — 무리 행동
- Mount — 이동
- Hauler — 운송
- Gatherer — 특정 자원 작업 보조
- Rare — 발견/수집

## 생태 시뮬레이션 단계

### Sleep

플레이어가 멀리 있을 때:

- 개체 전체 AI를 돌리지 않는다.
- 서식지 인구, 건강도, 이동 목적지만 데이터로 유지한다.

### Wake

플레이어가 접근하면:

- 필요한 개체를 생성한다.
- AI/전투/먹이 행동을 활성화한다.

### Settle

플레이어가 떠나면:

- 중요 상태를 서식지 데이터에 반영한다.
- 개체를 Sleep 상태로 되돌린다.

## 첫 MVP 생물

1. 소형 초식동물 — 사냥/가죽/고기
2. 대형 초식동물 — 위험하지 않지만 영역 반응
3. 소형 포식자 — 최초 전투 위협

고유 이름과 외형은 별도 디자인 단계에서 정한다.
