# 세력 설계 v0.1

초기 MVP에서는 복잡한 국가 정치보다 **기능이 명확한 세력**부터 만든다.

## 1. 항로국 (가칭)

표류섬의 출현을 관측하고 항로 정보를 거래하는 민간 네트워크.

게임 기능:
- 지도
- 섬 출현 정보
- 탐사 의뢰

## 2. 회수조합 (가칭)

표류섬과 폐허에서 자원/기술을 회수하는 기술자와 상인의 연합.

게임 기능:
- 제작
- 거래
- 희귀 부품

## 3. 정착연맹 (가칭)

닻섬 정착민의 느슨한 협의체.

게임 기능:
- 건축
- 공동 시설
- 거점 규칙

## 원칙

세력은 설정 설명용으로만 존재하지 않는다. 각 세력은 최소 하나의 플레이 시스템을 담당해야 한다.
