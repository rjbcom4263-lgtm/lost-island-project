## 작성 원칙

1. 게임 시스템으로 설명할 수 없는 설정을 무작정 늘리지 않는다.
2. 각 세계관 요소는 가능하면 하나 이상의 플레이 경험과 연결한다.
3. `초안 → 검토 → Canon` 단계를 거친다.
4. 기존 작품 연구 문서와 사라진섬의 Canon 문서를 분리한다.
