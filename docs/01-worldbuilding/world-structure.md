# 사라진섬 세계 구조 v0.1

## 세계 → 군도 → 섬 → 지역 → 청크

```text
사라진섬 세계
 ├ 닻 군도
 │  ├ 닻섬
 │  │  ├ 해안
 │  │  ├ 숲
 │  │  ├ 고지대
 │  │  └ 정착지
 │  └ 작은 표류섬
 └ 공백 해역
    ├ 표류섬
    └ 심층섬
```

게임 구현에서는 세계관 단위와 기술 단위를 맞춘다.

| 세계관 단위 | 게임 역할 | 기술 단위 |
|---|---|---|
| 해역 | 월드 선택/난이도권 | World Region |
| 군도 | 탐험 묶음 | Island Group |
| 섬 | 플레이 공간 | Island Scene/Data |
| 지역 | 바이옴/POI | Region |
| 청크 | 스트리밍/저장 | Chunk |
| 타일/셀 | 배치/지형 판정 | Cell |

## 섬 수명

모든 표류섬은 다음 상태를 가진다.

```text
미관측
 ↓
출현 예고
 ↓
활성
 ↓
불안정
 ↓
소멸
```

소멸한다고 모든 플레이어 진행을 삭제하지 않는다.

- 캐릭터/인벤토리: 유지
- 닻섬 건축: 유지
- 표류섬에 남긴 임시 시설: 소멸 가능
- 특별 회수품: 귀환 성공 시 유지

이 차이가 탐험의 긴장감을 만든다.

## Chunk 설계 원칙

각 청크는 다음 월드 상태를 저장할 수 있어야 한다.

- 자원 노드 상태
- 건축물
- 컨테이너
- 농작물
- 동물 서식지 상태
- 발견한 POI
- 환경 효과

플레이어가 없는 청크는 저비용 상태로 Sleep한다.
