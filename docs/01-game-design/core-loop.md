# 핵심 게임 루프

```text
탐색
 ↓
채집 / 사냥
 ↓
재료 확보
 ↓
제작
 ↓
거점 강화
 ↓
더 위험한 지역 준비
 ↓
탐험
 ↺
```

## 10~20분 초반 루프

1. 시작 지점 주변 탐색
2. 나뭇가지 / 돌 / 풀 확보
3. 임시 도구 제작
4. 음식과 안전한 장소 확보
5. 모닥불 설치
6. 첫 상자와 임시 거점 구축
7. 동물과 첫 전투 또는 회피
8. 다음 자원 지역을 발견하고 준비

## 금지할 설계

- 튜토리얼에서 수십 개 시스템을 한꺼번에 노출
- 초반부터 대규모 기지 건설 강요
- 멀티플레이가 없으면 진행 불가능한 콘텐츠
- 재료를 단순한 숫자 요구량으로만 사용하는 제작
