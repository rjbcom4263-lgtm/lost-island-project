# Durango V2 파일 감사 기록

> 상태: **Research — 사라진섬 Canon 아님**
>
> 확인일: 2026-09-14
>
> 대상: 사용자가 제공한 `D:\DurangoV2.exe`, `D:\DurangoV2_Data`, 런처 파일과 README

이 문서는 파일을 실행하거나 분해하지 않고, 파일 형식·메타데이터·폴더 목록·공개 저장소 설명만 확인한 기록이다. 타사 파일을 사라진섬 프로젝트의 코드·모델·텍스처·데이터로 가져오지 않는다.

## 판정표

| 파일/폴더 | 확인 결과 | 사라진섬에서의 사용 |
|---|---|---|
| `DurangoLauncher.exe` | 서명되지 않은 런처 실행 파일 | 사용하지 않음 |
| `DurangoV2.exe` | NEXON Korea 서명이 있는 Unity 2017.4.34 빌드 실행 파일 | 실행·복사·역공학 대상으로 사용하지 않음 |
| `DurangoV2_Data` | Unity의 `resources.assets`, `sharedassets`, `.resS`, `Managed` 어셈블리와 AssetBundle 묶음 | 게임 코드·에셋·데이터를 추출하거나 재포장하지 않음 |
| `UnityPlayer.dll` | Unity Technologies 서명의 Unity 런타임 DLL | 우리 Unity 프로젝트의 런타임으로 사용하지 않음 |
| `launch.token`, `launch.token.cache` | 런처 세션 파일 | GitHub·위키·채팅에 업로드하거나 내용 공개하지 않음 |
| `launcher.log` | 런처 진단 로그 | 공개 문서에 원문을 넣지 않음 |
| `Notion Setup 7.33.0.exe` | Notion 설치 프로그램 | 프로젝트와 무관 |
| `README.md` | Kyllox의 별도 Durango V2 프로젝트 설명 | 기능 아이디어만 연구자료로 참고 |

## 모델링·애니메이션 확인

독립된 `.fbx`, `.obj`, `.gltf`, `.glb`, `.blend`, `.dae` 파일은 확인되지 않았다. 대신 `DurangoV2_Data/StreamingAssets/AssetBundles` 아래에 다음과 같은 Unity 번들이 확인된다.

- `models$animals...` 동물 모델 번들
- `...prefab...` 프리팹 번들
- `...anim...` 이름을 가진 애니메이션 관련 번들
- `...materials...` 머티리얼 관련 번들
- 환경·소품·이펙트 번들

이 파일들은 독립 모델 파일이 아니라 게임 런타임이 읽는 포장 데이터다. 파일 이름만으로 메시, 본, 리깅, 텍스처의 권리를 판단할 수 없으며, 라이선스 확인 없이 추출·변환·Unity 재사용을 진행하지 않는다.

## README에서 얻는 연구 주제

README는 다음 기능을 별도 프로젝트의 기능으로 소개한다.

- 날씨 조정
- 건축 상호작용
- 펫 기능
- 전투 시스템
- 항해 시스템
- 자동 업데이트

사라진섬에 적용할 수 있는 것은 기능의 **문제 영역과 설계 질문**뿐이다.

```text
날씨       → 생존·채집·항해 위험이 어떻게 변하는가?
건축       → 건축물이 월드 저장과 어떻게 연결되는가?
펫         → 포획·길들이기·사육·운반을 어떤 규칙으로 관리하는가?
전투       → 플레이어와 생물의 판정·피해·도주를 어떻게 분리하는가?
항해       → 표류섬과 공백 해역을 어떤 이동 루프로 연결하는가?
업데이트   → 서버와 클라이언트 콘텐츠를 어떻게 안전하게 갱신하는가?
```

원본 코드, 클래스명, 수치표, UI, 모델, 텍스처, 사운드, 고유 지명은 사라진섬에 가져오지 않는다.

## 안전한 제작 방향

1. 웹 지도에서는 현재처럼 직접 작성한 SVG 생물 미리보기를 사용한다.
2. 실제 게임에서는 사라진섬 전용 로우폴리 생물을 Blender 또는 Unity에서 새로 만든다.
3. 애니메이션은 걷기·달리기·공격·도주·수영을 사라진섬의 생태 규칙에 맞춰 직접 설계한다.
4. 참고가 필요한 시스템은 이 문서의 질문과 공개된 일반 기술 문서로 다시 설계한다.

## 권리·출처 메모

README가 가리키는 [KylloxStudio/Durango_V2 공개 저장소](https://github.com/KylloxStudio/Durango_V2)는 별도 프로젝트다. 확인 시점의 저장소 화면에는 `LICENSE` 파일이 보이지 않았고, 공개되어 있다는 사실만으로 코드·실행 파일·게임 에셋의 재사용 허가를 의미하지 않는다.

## 결론

이 파일 묶음에서 사라진섬에 바로 사용할 수 있는 모델은 **0개**로 판정한다. 사용할 수 있는 결과는 기능 아이디어 목록과 Unity 게임 데이터가 어떻게 묶이는지에 대한 일반적인 관찰뿐이다. 모델·코드·번들은 새로 제작하거나 명시적인 재사용 라이선스가 있는 출처에서 별도로 구한다.
