# 연구 자료 운영 원칙

이 폴더는 기존 게임, 공개 발표자료, 오픈소스 프로젝트, 논문 등을 분석하는 공간이다.

## 제품 코드와 분리

연구 자료에서 발견한 아이디어와 구조는 재설계할 수 있지만 다음은 제품 저장소에 직접 포함하지 않는다.

- 타사의 원본 게임 코드
- 추출한 모델 / 텍스처 / 음악 / UI 리소스
- 권리자가 공개적으로 허용하지 않은 데이터 테이블
- 상표 / 로고 / 고유 세계관 명칭

## 문서 작성 방식

각 분석 문서는 다음 형식을 권장한다.

1. 출처
2. 무엇을 해결하는 시스템인가
3. 구조
4. 장점
5. 단점 / 버그
6. 사라진섬에서 참고할 부분
7. 그대로 사용하지 않을 부분
