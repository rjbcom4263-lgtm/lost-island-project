# Wiki 운영

현재 `docs/`가 프로젝트 지식의 Git 원본(source of truth) 역할을 한다.

Wiki.js에서는 초기에는 필요한 문서를 수동으로 옮겨도 되고, 추후 Git 기반 동기화/백업 방식을 결정한다.

## 권장 최상위 메뉴

1. 프로젝트
2. 게임 디자인
3. 기술
4. 연구 자료
5. 개발 현황
6. 결정 기록 (ADR)

## 편집 규칙

- 연구 내용과 확정 설계를 분리한다.
- 중요한 기술 결정은 `docs/05-decisions/ADR-*` 문서로 남긴다.
- TODO는 문서에 무한히 쌓지 말고 GitHub Issues로 이동한다.
- 구현과 다른 오래된 문서는 즉시 수정하거나 `Deprecated` 표시한다.
